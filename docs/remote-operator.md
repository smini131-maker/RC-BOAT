# RC 보트 육상 PC 보조 관제

## 출발 전

1. 보트에 둘 휴대폰의 핫스팟을 켜고 Jetson을 연결합니다. 휴대폰 RC 보트 앱에서 Jetson의 핫스팟 주소로 제어 연결을 열어 `SSH 연결됨`과 `ROS 정상`을 확인합니다. 앱이 화면에 표시된 상태를 유지합니다.
2. 육상 PC는 인터넷이 되는 Wi-Fi에 연결합니다. PC와 Jetson의 Tailscale은 같은 개인 사설망에 등록돼 있습니다. 이번 PC는 Windows에서 Tailscale 서비스가 자동으로 시작하고 로그인 세션이 없어도 연결을 유지하도록 설정했습니다.
3. PC 바탕화면의 `RC 보트 PC 보조 관제`를 엽니다. 프로그램은 Tailscale에서 `rcboat-jetson`을 찾고, Windows 자격 증명 관리자와 기존에 확인한 SSH 호스트 키를 이용해 연결합니다. 접속 후에는 수동 전환, 자동 대기, 카메라 켜기, 풍선 추적 시작, 비상정지를 사용할 수 있습니다. 풍선 추적 시작은 사용자가 확인한 때만 전송합니다.

## 연결 원리

육상 PC에서 시작한 명령은 Tailscale 사설망과 Jetson SSH를 거쳐 Jetson 내부 ROS 게이트웨이로 전달됩니다. 휴대폰은 보트 내부 핫스팟으로 별도의 제어 신호를 보냅니다. PC 보조 관제는 제어 신호를 주기적으로 발행하는 일반 관제 앱과 별도로 동작하므로 휴대폰의 제어 신호를 덮어쓰지 않습니다. 일반 Windows 관제 앱은 제어기로 한 대만 연결하는 기존 방식으로 사용합니다.

Tailscale은 서로 다른 인터넷에 연결된 장치를 사설 주소로 연결합니다. 네트워크 조건에 따라 직접 연결 또는 암호화 릴레이를 사용합니다. [Tailscale 연결 유형](https://tailscale.com/docs/reference/connection-types)

## 한계와 복구

- 육상 PC의 인터넷 또는 보트 휴대폰의 인터넷이 끊기면 PC에서 보내는 명령은 닿지 않습니다. 이때 보트 안 휴대폰과 Jetson 사이 제어 연결이 살아 있으면 기존 자동 모드가 유지될 수 있습니다. 현장 수동 회수는 RC 조종기를 사용합니다.
- 보트 안 휴대폰 앱이 백그라운드로 가거나, 제어 연결까지 끊기면 Jetson의 기존 수동 전환 규칙이 적용됩니다. 연결을 되찾은 뒤에는 상태를 확인하고 새로 출발을 눌러야 합니다. 재부팅 후 Jetson의 핫스팟·VPN 연결은 자동이며, 휴대폰 앱의 SSH 연결은 다시 확인합니다.
- 보조 관제는 현재 모드와 카메라 상태를 표시합니다. 지도 편집, 실시간 영상, 조이스틱은 기존 관제 앱에서 사용합니다.
- 이 PC의 연결 설정은 Windows 계정에 저장된 자격 증명과 `~/.rcboat/pc-companion.json`을 사용합니다. 새 PC에서는 사설망 가입과 해당 PC의 자격 증명 설정이 필요합니다. 비밀번호는 배포 파일에 포함되지 않습니다.

## 확인한 범위

Jetson v2.4.11의 Tailscale 주소로 PC에서 SSH 연결과 ROS 상태 조회를 확인했습니다. 출력이 잠긴 상태에서 PC가 보낸 자동 대기 명령이 정상 처리됐으며, 같은 시간에 휴대폰의 제어 신호가 계속 들어왔습니다. 실제 추진 구동과 대회 현장의 별도 Wi-Fi·휴대폰 데이터망 조합은 현장에서 확인해야 합니다.
