# Android 관제 앱 v2.4.11

비상정지 중에는 모든 탭 상단과 하단 제어부가 빨간색으로 바뀌며 ‘ESC·서보 출력 잠금’, 요청 사유·한국 시각을 표시합니다. 추적 시작 버튼도 잠금됩니다. 연결이 끊기면 마지막 확인 상태로 구분합니다. 해제 버튼은 확인 후 잠금만 풀고 자동 주행을 재개하지 않습니다. 파열 추정·목표 도착·실제 연결 단절은 수동 전환 사유로 표시합니다.

v2.4.2는 Jetson의 정상 입력 timeout 오판과 순간 중립 출력을 수정한 버전입니다. PC·모바일·Jetson의 버전을 맞춥니다. 모바일 화면과 조작 방식은 유지하며, 실제 단절 시 안전 수동 전환은 유지합니다.

Android 10 이상 휴대폰과 태블릿에 같은 APK를 설치합니다. 휴대폰은 하단 5개 탭, 태블릿은 좌측 메뉴와 넓은 지도·제어 패널을 사용합니다. Galaxy Tab S9+ 크기의 가로 화면도 지원합니다. Windows GUI의 기존 화면·버튼은 변경하지 않았습니다.

## 연결 상태와 영상

상단에 SSH와 ROS를 따로 표시합니다. 정상은 초록, 응답 지연은 노랑, 확인된 끊김은 빨강입니다. SSH는 연결 플래그만 보지 않고 원격 `true` 명령의 응답과 왕복 시간을 확인합니다. 한 번의 timeout은 지연으로 표시하고, 닫힌 SSH 세션 또는 반복 실패(3회 이상·첫 실패부터 8초 이상)는 끊김으로 표시합니다. 안전 제어의 기존 연결 만료 정책은 그대로 적용됩니다. 오래된 ROS 상태에서는 새 주행 시작을 막으며 수동 전환·비상정지는 계속 요청할 수 있습니다.

영상 수신은 상태 조회와 별도 주기로 동작하며 Jetson 생성 상한 12Hz에 맞춰 요청합니다. 표시 fps는 새 JPEG가 화면에 로드된 횟수입니다. 변경되지 않은 JPEG는 ETag/304로 본문을 재전송하지 않고, 휴대폰에는 최신 JPEG 한 장만 유지합니다. JPEG를 base64 문자열로 JavaScript에 반복 전달하던 방식은 앱 내부 이미지 주소로 바꿨습니다. 숨겨진 지도·GPS 화면도 매번 다시 그리지 않습니다. 실제 fps는 카메라·Jetson·Wi-Fi·화면 상태에 따라 달라집니다.

`LIVE`는 최신 원본 영상일 때만 표시합니다. 1.5초 넘게 새 영상이 없으면 `영상 지연`, 4초 넘으면 이전 영상을 가리고 수신 대기를 표시합니다. ROS 조회가 지연돼도 새 카메라 영상이 계속 들어오면 영상은 유지합니다. 카메라 촬영·AI 처리 자체가 느린 경우와 네트워크 지연은 구분해서 봅니다.

## 설치와 연결

1. `dist/RCBoatMobile_v2.4.11.apk`를 휴대폰 또는 태블릿에 설치합니다. 연결된 휴대폰에는 USB 디버깅으로 설치할 수 있습니다.
2. Jetson에 v2.4.3을 배포하고 ROS를 실행합니다. 기존 항로·NTRIP 로컬 설정은 그대로 사용합니다. v2.4.1은 작은 풍선 원거리 감지와 1080p 설정을 추가하며 기존 상승률 120 PWM/s와 안전 제어는 유지합니다.
3. 휴대폰을 Jetson에 접근할 수 있는 같은 Wi-Fi/네트워크에 연결합니다. 앱 상단 **연결 설정**에서 Jetson IP, gateway 8765, SSH 22, 사용자 `jetson`을 입력합니다. SSH 비밀번호를 입력하면 제어 연결, 비워두면 상태 조회 연결입니다.
4. 처음 연결할 때 표시되는 SSH 호스트 키를 확인합니다. 변경된 호스트 키는 거부합니다. SSH 비밀번호·gateway 토큰은 메모리에서만 사용하고 저장하지 않습니다. IP·포트·사용자명만 휴대폰에 저장합니다.

PC와 모바일 중 한 관제 앱만 제어 연결합니다. 기존 backend는 단일 operator-link를 사용하므로 동시 제어를 지원하지 않습니다. 조회 전용 모바일 연결은 operator-link를 발행하지 않습니다. 모바일 앱을 나가거나 화면을 끄면 수동 전환을 요청하고 SSH 연결을 해제합니다. 통신 자체가 끊겨 요청이 전달되지 않으면 기존 Jetson 안전감독의 연결 만료 처리를 따릅니다. 다시 열어도 자동 주행을 재개하지 않습니다.

## 화면과 동작

- **운항:** OpenStreetMap 배경, 저장 항로·웨이포인트 번호·현재 GPS 위치·이동 궤적, 대루트/소루트 선택, 주행 시작과 수동 전환, 순항 PWM 편집·적용 확인을 제공합니다. 주행 시작 시 실제 출력 확인창이 표시됩니다. 배경 지도는 인터넷이 필요하며 지도 다운로드가 실패해도 좌표와 항로 선은 표시합니다.
- **항로:** 유효 GPS 기반 기록 시작/종료 후 저장/취소, 소루트 좌표 추가·수정·삭제, n개 소루트를 묶는 Multi-Path 관리, 전체 항로 CSV/JSON 다운로드를 제공합니다. CSV에는 항로 ID·이름·웨이포인트 번호·위경도·UTM을 포함합니다.
- **풍선** 탭에서 Jetson이 처리한 실시간 영상과 감지 상자를 볼 수 있습니다. 추적 시작을 누르면 최대 30초 동안 카메라 준비를 기다립니다. BALLOON으로 전환한 뒤 새 프레임에서 풍선을 획득합니다. 수동 전환이나 카메라 끄기 이후에는 다시 추적 시작을 눌러 새 대상을 획득합니다.
- **GPS·RTK:** 정상 범위와 색상, UTC·UTM·데이터 지연·RTCM 수신 경과·수신기 보정 나이를 구분합니다. 미제공 값은 `unsupported`/`no_data`, 통신 두절 후 이전 값은 `stale`로 표시합니다. Jetson의 NTRIP 설정과 사용자명을 불러오며 비밀번호는 Jetson 저장값을 유지합니다. 마지막으로 불러오거나 수정한 Host·Port·Mount Point·사용자명·TLS는 휴대폰 로컬에 보존하여 Jetson 없이 앱을 다시 열어도 표시합니다. 계정/서버 프로필을 APK나 GitHub에 넣지 않습니다. 로컬 프로필 공유 가져오기는 저장 확인창을 표시하고 비밀번호·토큰을 제외하며 장치 연결이나 보정 접속을 시작하지 않습니다. HDOP 편집 중 폴링으로 값이 덮어써지지 않습니다.
- **테스트·설정:** 선택한 대루트/소루트의 도보 테스트 시작·재개·정지, 완료한 테스트 또는 최신 완료 테스트 ZIP 다운로드, 풍선 로그 다운로드, 손을 떼면 중립으로 돌아오는 2축 조이스틱 원격 조종, 연결별 상태·명령 기록을 제공합니다. ZIP은 SHA-256 검증 후 **다운로드/RCBoat/**에 저장합니다. 큰 ZIP(응답 48 MiB 초과)은 기존 PC 다운로드를 사용합니다.

수동 전환·비상정지 버튼은 모든 탭 하단에 고정되고, 상단 모드 변경 메뉴는 어느 화면에서든 사용할 수 있습니다. 수동 전환에는 확인창이 없으며 즉시 요청합니다. 조이스틱은 기존 PC 원격과 같이 좌측 4900·우측 7300, 전진 7397·후진 5800, 중앙 6000/6450을 사용하며 8% 중앙 데드밴드와 범위 제한을 적용합니다. 손 떼기·포인터 취소·화면 전환·연결 만료 시 중립을 요청하고, UI 입력이 멈추면 기존 REMOTE timeout도 적용됩니다. 비상정지·수동 전환·도보 테스트 정지는 SSH 확인 또는 상태 조회·영상·ZIP 다운로드 완료를 기다리지 않고 별도 실행 경로로 기존 gateway에 전달합니다. 새 연결을 만들면 이전 연결에 대기 중이던 명령은 취소합니다. 모바일/Jetson 버전이 다르거나 SSH 제어 연결·신선한 상태가 없으면 주행을 시작할 수 없습니다. 기존 RC·GPS·E-STOP·출력 잠금·모드·범위 검사는 Jetson에서 다시 적용됩니다.

## Windows 빌드

JDK 17 이상과 Android SDK 36/build-tools 35.0.0이 필요합니다. SDK 경로가 다르면 `ANDROID_HOME`을 지정합니다. Gradle 8.13은 wrapper로 받습니다.

```powershell
Set-Location -LiteralPath "C:\Users\smini\OneDrive\바탕 화면\RCBoatControl_Complete_2026-09-25_UPDATED\RCBoatControl_v2.4.11"
$env:ANDROID_HOME = "$env:USERPROFILE\AndroidSdk"
& .\mobile_android\build.ps1 -Install
```

빌드는 한글 OneDrive 경로를 피하도록 `%LOCALAPPDATA%\RCBoatBuild\android`에 소스를 준비합니다. 결과 APK는 프로젝트 `dist`에 저장합니다. 릴리스 서명 키와 비밀번호는 `%USERPROFILE%\.rcboat\rcboat-mobile.jks`, `android-signing.properties`에만 생성하고 Git에서 제외합니다. 향후 동일 앱 업데이트에 필요하므로 이 두 로컬 파일을 보존합니다. 개발/배포용 자체 서명이며 Play Store 등록은 수행하지 않았습니다.

## 검증 범위

v2.4.4 지도는 GPS가 먼저 수신돼도 뒤이어 도착한 저장 항로를 표시합니다. 선택한 대루트·소루트로 초점을 맞추고, 전체 보기는 모든 항로를 포함합니다. 같은 대루트 안의 활성 소루트 변경은 사용자가 이동한 화면을 되돌리지 않습니다. 가까운 웨이포인트 번호 배지는 화면에서 32px 간격을 두며 확대·이동 후 다시 배치합니다. 좌표·번호 원본과 항로선의 모든 지점은 그대로 보존합니다. 연결 전·불러오는 중·실제 빈 저장소를 서로 다른 문구로 표시합니다. 모바일 확인창의 확인·취소, 조회 전용 해제 안내, 지도 표시 순서·선택 변경·전체 보기·화면 이동 보존·밀집 번호 겹침 방지를 4개 화면 크기에서 검사합니다.

실제 SM-S938N/Jetson v2.4.4에서 모바일 해제 확인창을 눌러 취소 시 E-STOP 유지, 확인 시 backend 해제·MANUAL 전환·armed=false를 확인했습니다. 시험 종료 후 AUTO_SAFE·출력 잠금·6000/6450을 확인했습니다. 저장 항로 7개·대루트 2개 수신과 해수천 지도 표시도 실기기에서 확인했습니다.

v2.4.3은 상단 기존 모드 버튼에 현재 상태 한 가지만 표시합니다. 수동 전환·비상정지 버튼 위치는 유지하며, E-STOP 작동 시 모든 탭의 빨간 배너와 하단 `비상정지 ON`으로 구분합니다. 해제 확인은 Android 네이티브 창에서 처리하며 취소·앱 이탈·연결 변경 시 명령을 보내지 않습니다. 조회 전용 연결에서는 해제 버튼으로 SSH 비밀번호 입력 안내를 엽니다. 제어 연결에서 확인을 누르면 해제 명령 후 상태를 재조회하며, 수동 중립 재허용과 별도 운항 시작 절차는 유지합니다. 연결/상태가 오래되면 현재 모드 대신 지연·연결 끊김을 표시합니다. 영상은 HTTP 연결을 재사용하고 실제 이미지 표시 완료 횟수로 미리보기 fps를 계산합니다. 실제 연결 휴대폰에 v2.4.3 APK 업데이트 설치를 확인했습니다.

소프트웨어 검증은 Python 회귀 테스트 164개, Qt 검사 5개, Android TCP·로컬 프로필·연결 상태·영상 캐시 테스트 15개(분할 UTF-8·거부·중단·크기 제한·주소 검증), Android lint, 360×800·412×915·800×1280·1400×876 화면의 잘림/주행 버튼 위치/PWM ACK와 편집값 유지/기록 저장 조건/NTRIP 로컬 프로필·사용자명 유지/비밀번호 보존/모든 탭 수동 전환·모드 변경/조이스틱 끝점·중립 복귀/버전 불일치·연결 만료를 포함합니다. UI 테스트는 합성 상태를 사용하며 실물 모터·수상 주행·풍선 파열 시험이 아닙니다. Tab S9+는 화면 크기 검증이며 실기기가 연결되지 않았다면 실기기 검증으로 보지 않습니다. 이전 v2.3.3 작업에서는 연결된 갤럭시 휴대폰(SM-S938N/Android 17)에 릴리스 서명 APK를 설치하고 실제 앱 시작·운항/GPS·테스트 화면, 시스템 상태바/제스처 영역 겹침 수정을 확인했습니다. v2.4.1은 새 APK 빌드·서명과 실제 SM-S938N에 업데이트 설치·실행·상단 연결 상태 표시를 확인했습니다. Jetson 소스·실행 버전과 실제 영상 전송은 장치 적용 후 별도로 확인합니다. 수상 출력·풍선 파열 검증은 포함하지 않습니다.

```powershell
Set-Location .\mobile_android
npm install
npx playwright install chromium
npm test
```
