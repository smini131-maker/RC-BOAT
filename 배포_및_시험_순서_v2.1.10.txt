[유지되는 보정/버전 기능]
1) 'RTCM 수신 후 경과': Jetson이 CRC 정상 RTCM3 메시지를 마지막으로 수신한 뒤 경과한 초.
   수신 대기/재접속 중에도 0.5초마다 갱신합니다. 5초 초과는 stale, 첫 수신 전은 no_data입니다.
   TCP 바이트만 들어오거나 CRC가 틀린 메시지는 보정 수신 시각을 갱신하지 않습니다.
2) '수신기 보정 나이': GPS 수신기가 NMEA GGA에 보고한 보정 나이. 미제공 시 no_data/unsupported.
   위 두 값은 RTK FIX 성공 여부와 별개입니다. 수신 경과는 서버에서부터의 전송 지연 측정값도 아닙니다.
3) SSH 생존 확인은 별도 스레드 한 곳만 수행합니다. 2초 응답 제한을 2회 연속 넘겨야 단절로 판정합니다.
   지연 1회 후 회복하면 기존 세션을 유지합니다. 터미널 exit/닫힘/인증 transport 종료는 즉시 반영합니다.
   실제 단절 확정 시 MANUAL 전환하며 GUI/통신 전체 소실 시 Jetson의 5초 링크 만료도 유지합니다.
   응답 지연/회복/단절 사유를 GUI 운항 기록에 구분해 남깁니다. 실제 Wi-Fi 불량 자체를 해결하는 기능은 아닙니다.
4) ROS gateway 카드에 실행 중인 Jetson 버전을 표시합니다. GUI/백엔드 버전 불일치 시 신규 항법/원격/도보
   운항 시작을 거부하지만 비상정지/수동 전환/도보 정지/조회/다운로드는 계속 허용합니다.
5) GPS UBX/NMEA 카운터를 실제 backend 값에 연결했습니다.
6) 설치는 전송 파일 해시, package 버전, 재시작된 gateway의 실제 소스 경로/해시, GPS/NTRIP/safety 실행 버전까지
   모두 확인해야 성공합니다. 이전 build/devel 캐시는 재생성합니다. rcboat_ros_data의 항로/NTRIP/로그는 보존합니다.
